# Klepa Up — Telegram-бот + Mini App (версия 5, новогодняя)

Полный комплект: приложение, сервер, бот, база, банк, QR, чаты, канал, рынок, настройки, админ-панель и новогоднее оформление. Все файлы лежат в корне, без папок. Загружайте на GitHub ВСЕ файлы из списка.

## Обновление (данные не теряются)
1. GitHub → Add file → Upload files: загрузите все 20 файлов с заменой.
2. Render пересоберёт сервис сам. База прежняя: игроки, балансы, промокоды, отзывы, роли, переводы сохраняются.

Призы выдаёт сервер, дату на телефоне подделать нельзя, пропущенные двери можно открыть до 15 января. Призы: 500 звёзд, Jester Hat, 2 000 звёзд, Santa Snake, 5 000 звёзд, Spiced Wine, Nightmare Monkey + 3 000 звёзд. Год календаря задаётся `ADV_YEAR`.

## Переход на нового бота
1. Render → Environment: `BOT_TOKEN`, `OPENROUTER_KEY`, `PUBLIC_URL` с `https://`; `DATABASE_URL` не менять.
2. @BotFather → Configure Mini App / Main App → укажите `PUBLIC_URL`.
3. Добавьте бота администратором канала @KlepaUp (проверка: Админ-панель → Обзор).
4. Откройте бота и нажмите /start. Токены вписывайте только в Render.

## Возможности
Админ-панель со счётчиками (игроки с фильтрами, баны с причиной и сроком, заявки на галочку, поддержка, рынок, промо, переводы, отзывы, рассылка, журнал), защита владельца и админов, окно блокировки с поддержкой, банк и QR, чаты и канал с фото и видео, рынок игроков (комиссия 5%), номера 6 стран, коллекционные юзернеймы, бонус 10 000 звёзд за каждые 10 приглашённых, настройки (7 цветовых схем, 5 шрифтов, звук, вибрация), ИИ-помощник через сервер.

## Важно знать
- Баланс и подарки хранятся в приложении игрока, сервер получает копию каждые 15 секунд.
- Файлы чата и канала лежат в базе Postgres. Бесплатная база Render живёт 30 дней и вмещает около 1 ГБ: для постоянной работы возьмите платный план или внешний Postgres (Neon, Supabase).
- Без `DATABASE_URL` данные пишутся в `data.json` и папку `media` (только для теста).
- Локальный запуск: `npm install`, затем `BOT_TOKEN=... PUBLIC_URL=... node server.js`.
